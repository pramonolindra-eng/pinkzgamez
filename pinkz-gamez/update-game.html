📌 Cara Update ke Website

1

Tambah semua game di form atas, lalu klik Copy JSON

2

Buka GitHub → folder data → klik file games.json → klik ✏️ edit

3

Select all isinya → hapus → paste JSON yang sudah dicopy → klik Commit changes

4

Upload foto cover ke GitHub → folder img/games/ → nama file sesuai kolom img di JSON

5

Cloudflare otomatis deploy ulang dalam ~1 menit — selesai!
